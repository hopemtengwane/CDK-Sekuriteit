# CDK Sekuriteit website

A responsive, static website for Cradock Sekuriteit (CDK Security), based in Cradock, Eastern Cape.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript; there is no build step or package installation.

## Publish with GitHub Pages

1. Create a GitHub repository and push the files in this folder to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub Pages will provide the public site URL when deployment finishes.

## Files

- `index.html` — page content, styling and responsive navigation.
- `assets/cdk-logo-transparent.png` — CDK crest with the surrounding blue background removed.
- `assets/solar-4g-camera-promo.png` — supplied camera promotion.
- `assets/paradox-alarm-kit-promo.png` — supplied alarm kit promotion.

Contact details and product offer information are based on CDK's public listings, Facebook page and supplied promotional images. Confirm that phone numbers, service areas, current stock and special pricing remain accurate before publishing publicly.
